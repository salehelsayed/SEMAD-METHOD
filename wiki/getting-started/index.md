## Installation Overview

SEMAD can be installed in two ways:

### 1. NPX Installation (Recommended)
```bash
npx bmad-method install
```

### 2. Manual Installation
```bash
git clone https://github.com/your-repo/semad-method.git
cd semad-method
npm install
npm run build
```

## First Steps

2. **Initialize a new project** with the agent orchestrator

## Key Concepts to Understand

Before diving in, familiarize yourself with:

- **Agents**: AI-powered entities that handle specific development roles
- **Workflows**: Predefined sequences of agent interactions
- **Stories**: Context-rich implementation units
- **Templates**: Reusable document structures
- **Tasks**: Specific actions agents can perform
